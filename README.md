# Overview
This repository contains code and data for generating the primary results from "Hierarchical Community Structure of the Adult Drosophila Connectome Reveals Conserved Circuit Archetypes."

The code is divided into two components:
1. `py/sample_posterior_distribution_no_threshold.ipynb` fits the nested stochastic blockmodel to the FAFB connectome. The sampling procedure takes a long time given the size of the connectome. For convenience, the data directory includes an edge list for the connectome (`data/drosophila_adult_no_threshold.npy') and the partition generated by the notebook (`data/final_partition_no_threshold.npy`). We used this partition for all analyses in the main text. Note: if you opt to run the notebook on your own, the hierarchical partition will likely differ from ours due to stochasticity in the optimization algorithm.
2. `m/run_analyses.m` performs analyses to generate Figures 2-8 (note that Figure 1 is simply a schematic). The scripts for each individual figure (e.g. `figure*.m`) include some computationally intense steps. For convenience, we have run these script and saved intermediate outputs. These are available in the `outputs/` directory.

To run analyses, first download and unzip this repository.
