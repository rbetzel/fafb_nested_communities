# Overview
This repository contains code and data for generating the primary results from "Hierarchical Community Structure of the Adult Drosophila Connectome Reveals Conserved Circuit Archetypes."

The code is divided into two components:
1. `py/sample_posterior_distribution_no_threshold.ipynb` fits the nested stochastic blockmodel to the FAFB connectome. The sampling procedure takes a long time given the size of the connectome. In the `data` directory, we include the modal partition generated by this script (`data/final_partition_no_threshold.npy`). We used this partition for all analyses in the main text. Note: if you opt to run the notebook on your own, the hierarchical partition will likely differ from ours due to stochasticity in the optimization algorithm.
